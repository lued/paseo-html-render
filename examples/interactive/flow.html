From a commit to a release

A four-stage release path. Each stage names the decision and the check that keeps the next one honest.

All stage details are listed below.Click a stage, or focus it and use the arrow keys.

What happens at each stage

Build
Compile the app and bundle assets from the locked dependency tree.Check: lockfile unchanged and output reproducible.
Verify
Run the focused tests and a browser smoke check against a production build.Check: tests pass and the console stays clean.
Stage
Publish to a staging URL and inspect the real page at phone and desktop widths.Check: no horizontal overflow and the static view stays readable.
Release
Promote the verified build and watch the first health checks.Check: the rollback path is known before traffic moves.
