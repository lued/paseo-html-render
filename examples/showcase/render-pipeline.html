01 · Ask

Start with the question, not a template

“Compare these screenshots.” “Map this flow.” “Show the last six deploy steps.” The agent decides whether a card answers it better than prose, and writes the page for that one request.

02 · Compose

One page that still makes sense without scripts

HTML, inline CSS, inline SVG and workspace raster images. Remote fonts, scripts, styles and images are blocked, so the page is portable by construction.

03 · Preview

See the static result before anyone else does

html_preview captures a PNG with JavaScript disabled and reports the content height. That is also the image a phone or a script-disabled viewer may see, so the page has to read without interaction.

04 · Publish

The card appears above the reply

html_render stores the artifact privately and mounts the live frame on web and desktop. The final reply keeps a link to interactive.html; native clients get a static image or the native report.

Local diagram controls only. The page cannot control Paseo agents, workspaces or files. Remote resources stay blocked; host link and image opening is limited to the documented frame messages.
