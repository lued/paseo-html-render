How new ideas enter this plan

One project tracker records each idea, its lane, owner, status and next action. Completion/error notifications return work to the orchestrator for inspection. Compatible ideas can steer an active lane; conflicting work waits instead of silently replacing it. No extra worktree is created just to store an idea.
